# Retail Sales Analysis

Este proyecto tiene como objetivo analizar y predecir las ventas de una tienda de retail utilizando técnicas de ciencia de datos. Se trabajan distintas etapas, desde la carga y exploración de datos hasta visualización y predicción con modelos de machine learning.

## Estructura del Proyecto

```
retail-sales-analysis/
│
├── data/                 # Archivos de datos (CSV)
│   └── retail_sales_dataset.csv
│
├── notebooks/            # Notebooks de análisis exploratorio y modelado
│   └── 01_analisis_basico.ipynb
│
├── src/                  # Código fuente (funciones reutilizables)
│   └── carga_numpy.py
│
├── README.md             # Descripción general del proyecto
└── requirements.txt      # Dependencias del proyecto (si aplica)
```

## Instalación

1. Clona este repositorio:

```
git clone https://github.com/tu_usuario/retail-sales-analysis.git
cd retail-sales-analysis

```

2. (Opcional) Crea un entorno virtual:

```
python -m venv venv
source venv/bin/activate      # En Linux o macOS
venv\Scripts\activate       # En Windows

```

3. Instala las dependencias necesarias:

```
pip install pandas numpy jupyter

```

## Uso

Ejecuta Jupyter Notebook desde la carpeta raíz del proyecto:

jupyter notebook
Luego abre el archivo ubicado en:
notebooks/analisis_basico.ipynb

para comenzar con el análisis.
